# 초록

초록은 '배움에서 나눔으로'를 슬로건으로 활동하는 개발자 커뮤니티입니다.🌱

좋은 교육 경험을 나누고 함께 성장하는 흐름을 만들어갑니다.

[홈페이지](https://cho-log.github.io/) 에서 자세한 내용을 만나보실 수 있어요!

## 아카이브에 내 활동 기록 남기기

초록스터디 리드와 리뷰어, 초록해듀오 멘토는 본인의 활동 기록을 [아카이브](https://cho-log.github.io/archive)에 등록하거나 기존 기록을 수정·삭제할 수 있습니다.

1. [이슈 페이지](https://github.com/cho-log/cho-log.github.io/issues)에서 **New issue**를 선택합니다.
2. 등록, 수정, 삭제 중 원하는 폼을 선택하고 내용을 작성합니다.
3. 자동으로 생성된 PR을 운영진이 검토하고 머지합니다. 이후 배포가 완료되면 아카이브에 반영됩니다.

직접 저장소를 Fork하거나 코드를 수정할 필요는 없습니다.
등록 대상과 공개 정보, 검토 절차는 [기여 가이드](CONTRIBUTING.md)를 확인해주세요.

## 코드와 문서 기여하기

오탈자 수정, 화면 개선, 버그 수정 등 홈페이지를 개선하는 기여도 환영합니다.

이 저장소를 Fork한 뒤 변경 사항을 작성하고, 원본 저장소의 `main`을 대상으로 PR을 제출해주세요.
자세한 참여 방법은 [기여 가이드](CONTRIBUTING.md)를 확인해주세요.
