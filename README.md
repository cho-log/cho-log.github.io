# 초록

초록은 '배움에서 나눔으로'를 슬로건으로 활동하는 개발자 커뮤니티입니다!🌱
좋은 교육 경험을 나누고 함께 성장하는 흐름을 만들어갑니다.

[홈페이지](https://cho-log.github.io/) · [아카이브](https://cho-log.github.io/archive) · [기여 가이드](CONTRIBUTING.md)

## 내 활동 기록 등록하기

초록스터디 리드·리뷰어와 초록해듀오 멘토는 본인의 활동 기록을 PR로 등록할 수 있습니다.

1. 이 저장소를 본인 계정으로 Fork합니다.
2. Fork한 저장소의 `src/data/leads.ts`에 자신의 기록을 추가합니다. GitHub 웹에서 수정할 수 있으며, 로컬 설치·실행은 필수가 아닙니다.
3. 원본 저장소의 `main`을 대상으로 PR을 제출하고, 활동 설명과 본인 확인·공개 동의 항목을 작성합니다.

등록된 본인 기록의 수정·삭제도 같은 방식으로 PR을 제출할 수 있습니다.

데이터 작성 방법, 선택 증빙, 검토 절차와 수정·삭제 안내는 [기여 가이드](CONTRIBUTING.md)를 확인해주세요.
